# Weather App

## Project Description

A Python application that fetches and displays real-time weather information for a user-specified city using the OpenWeatherMap API.

## Features

- Get current temperature
- Display humidity
- Show weather condition
- Display wind speed
- Uses real-time weather data

## Technologies Used

- Python 3
- Requests Library
- OpenWeatherMap API

## How to Run

1. Install requests library:
   pip install requests

2. Run the program:
   py weather_app.py
