# BMI Calculator

## Project Description
BMI Calculator is a simple Python application that calculates a user's Body Mass Index (BMI) based on their weight and height.

## Features
- Accepts weight and height as input
- Calculates BMI
- Displays BMI category
- Handles invalid input

## Technologies Used
- Python 3

## How to Run

python bmi_calculator.py
