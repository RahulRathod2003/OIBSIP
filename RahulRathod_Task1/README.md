# BMI Calculator

## Project Description
BMI Calculator is a simple Python application that calculates Body Mass Index (BMI) using weight and height.

## Features
- Accepts weight and height as input
- Calculates BMI
- Displays BMI category

## Technologies Used
- Python 3

## How to Run

python bmi_calculator.py
