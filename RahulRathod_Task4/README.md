# Voice Assistant

## Project Description

A simple Python Voice Assistant that responds to user commands and provides useful information such as time and date.

## Features

- Greets the user
- Tells current time
- Displays current date
- Introduces itself
- Exit command

## Technologies Used

- Python 3
- pyttsx3
- datetime

## How to Run

1. Install required library:
   pip install pyttsx3

2. Run the program:
   py assistant.py

## Available Commands

- hello
- time
- date
- your name
- exit
