# Chat Application

## Project Description

A simple Python Chat Application that simulates a conversation between a user and a chatbot. The chatbot responds to predefined commands and provides interactive communication through the terminal.

## Features

* User-friendly chat interface
* Responds to greetings
* Answers simple questions
* Displays chatbot name
* Exit command to end the conversation

## Technologies Used

* Python 3

## Available Commands

* hello
* how are you
* your name
* bye

## How to Run

1. Open Terminal or Command Prompt.
2. Navigate to the project folder.
3. Run the program:

```bash
py chat_app.py
```

## Sample Output

You: hello

Bot: Hello Rahul!

You: how are you

Bot: I am fine. How are you?

You: your name

Bot: My name is ChatBot.

You: bye

Bot: Goodbye Rahul!
